# Anime Store

## Description
Anime Store is a full-stack web application that allows users to browse and manage anime products.  
The project uses a Java backend with Spring Boot and a React frontend.

## Features
- View anime products
- Add new products
- Update product details
- Delete products
- REST API integration

## Technologies Used
Backend:
- Java
- Spring Boot

Frontend:
- React
- JavaScript
- HTML
- CSS

## How to Run

Backend:
1. Navigate to the backend folder
2. Run the Spring Boot application

Frontend:
1. Navigate to the frontend folder
2. Install dependencies

```bash
npm install
npm start
